# Тайм2гаджет (Time2Gadget)

Компактный настольный таймер для Windows 10/11 в виде виджета: круглый циферблат с пресетами
(5–90 минут), сегментные цифры, звонок и визуальные эффекты по окончании, компактный режим,
живая иконка в трее с прогрессом, настраиваемые клавиши и до 5 «быстрых таймеров» на глобальных
клавишах или кнопках мыши.

## Возможности

**Таймер**
- Кольцо из 8 секторов-пресетов (5–90 минут): клик — сразу старт; повторный клик по идущему — добавить его время;
  клик по другому — начать заново. Колесо мыши над центром — ±1 минута.
- Старт/пауза, сброс, крупные сегментные цифры, текущее время и дата под таймером.
- Компактный вид (клик по центру циферблата) — маленькое окно-часы; размер полного и компактного вида
  настраивается отдельно, каждый вид помнит своё место на экране.

**Быстрые таймеры** (до 5)
- Имя (по умолчанию «Таймер N»), время ДД:ЧЧ:ММ:СС и своя глобальная клавиша: любое сочетание с Ctrl/Shift/Alt/Win или кнопка мыши
  (средняя, «Назад», «Вперёд»). Работает в любой программе, даже когда окно в трее.
- У каждого — свой эффект по окончании и свой звук: встроенный звонок или свой файл, громкость, устройство
  вывода. По умолчанию звук выключен — только эффект.
- **Панель быстрых таймеров**: окошко высотой с компактный вид, в нём таймеры с переключателем «в панели» — каждый идёт сам по себе:
  плей/пауза, сброс, имя и время (только нужные разделы). Свой эффект хода (заливка, убывающая заливка, полоска, деления)
  и его цвет, свой эффект окончания (мигание, вспышки, пульсация), галочка «сбросить и закрыть». Показ и скрытие —
  кнопкой в окне «Быстрые таймеры» или клавишей (по умолчанию выкл., Ctrl+Shift+Insert).

**Клавиши**
- Старт/пауза, сброс, компактный вид, показать/скрыть окно — назначаются в настройках.
- У каждой клавиши режим: только в окне таймера или глобально (везде). Esc в окне всегда сбрасывает.

**Звук**
- 18 встроенных звонков или свой файл (копируется к программе), выбор устройства вывода, громкость,
  число повторов звонка.
- Прослушивание прямо в списке: ▶/■, длительность каждого звонка, остановка с плавным затуханием.

**Визуальные эффекты**
- Во время отсчёта и по окончании: пульсация, вспышки, дыхание цветом, радужная волна, встречные волны
  по кольцу, змейка по рамке, радужная змейка. Любой эффект можно посмотреть на циферблате прямо из настроек.
- Длительность эффекта окончания настраивается (или до сброса). По умолчанию: встречные волны во время
  отсчёта, радужная волна по окончании.

**После окончания**
- Кнопка рядом с крестиком: левый щелчок — перейти в компактный вид, правый — свернуть в трей или закрыть.

**Трей и окно**
- Программа живёт в трее: живая иконка с прогрессом и эффектами окончания; мигает, если окно скрыто.
- Автозапуск с Windows, «поверх всех окон», поведение крестика (свернуть или закрыть).

**Сон и мониторы**
- Будить компьютер к окончанию таймера и включать погасшие мониторы.
- **Фоновая заставка и слайдшоу экрана:** статичная заставка — у каждого монитора своя картинка (плитка монитора с превью, клик ЛКМ — окно выбора) и свой режим (растянуть, по размеру, заполнить, по центру) или сплошной цвет; слайдшоу по расписанию (раз в час, раз в сутки, свой интервал) — до 30 шагов на каждый монитор, картинки перетаскиваются по шагам, эффекты смены (растворение, сдвиг, шторка, наплыв, пиксельное растворение, дисперсия, распад) своим окном-подложкой за значками рабочего стола; экспорт и импорт всего одним архивом; закрепление слайд-шоу Windows.
- По желанию — открывать окна программ и игр (оконных) там, где их закрыли: то же место и размер при новом запуске.
- **Размер и положение окон программ** — положение, размер, «окно без рамки» и «не выпускать указатель мыши из окна» (с клавишей включения) для окон других программ и игр, по желанию — своя клавиша открытия этого окна с уже выбранным активным окном: быстрые кнопки по углам и сторонам монитора, точные значения, «перечитать окно»; профиль можно назначить программе — он применится сам при её запуске и если она поменяет размер (как Simple Runtime Window Editor, но автоматически).
- По желанию — возвращать окна других программ на их мониторы после сна и/или гашения мониторов
  (с опцией запуска с правами администратора — для окон программ «от администратора»).

**Прочее**
- Обновления: автопроверка при каждом запуске (и после перезагрузки) и раз в сутки, установка из программы; кнопка отчёта VirusTotal по вашей версии.
- Сброс всех настроек и положения окон одной кнопкой; подсказки ко всем элементам.

## Установка

Скачайте `Time2Gadget-win-Setup.exe` со страницы [Releases](https://github.com/alexan-moscow/time2gadget/releases)
и запустите. Программа ставится для текущего пользователя, права администратора не нужны.
Если на компьютере нет .NET 8 Desktop Runtime, установщик предложит его установить.
Установленная версия обновляется сама — проверяет обновления при запуске и раз в сутки.

Без установки: `Time2Gadget-win-Portable.zip` — распакуйте в любую папку и запустите `Тайм2гаджет.exe`
(нужен .NET 8 Desktop Runtime). Портативная копия сама себя не обновляет: при новой версии кнопка в настройках
открывает страницу выпуска.

Файлы пока не подписаны цифровой подписью, поэтому Windows SmartScreen может показать
предупреждение: «Подробнее» → «Выполнить в любом случае».

## Антивирусы и ложные срабатывания

Файлы программы пока не подписаны цифровой подписью. Неподписанные самораспаковывающиеся установщики
(установщик Velopack распаковывает программу в профиль пользователя и запускает её) иногда помечаются
эвристиками машинного обучения — это видно по суффиксу `!ml` / `ml.score` в названии срабатывания, например
`Trojan:Win32/Wacatac.C!ml`. Это не найденный вирус, а «похоже на» по формальным признакам.

Для каждого выпуска в его описании есть ссылка на отчёт VirusTotal; о ложных срабатываниях сообщается
производителю антивируса, номер заявки и результат указываются там же. Исходный код полностью открыт —
его можно проверить и собрать самостоятельно (ниже). Кнопка «Проверка на VirusTotal» в настройках программы
открывает отчёт именно по установщику вашей версии.

## Сборка из исходников

Нужен .NET 8 SDK.

```
dotnet build src/Time2Gadget/Time2Gadget.csproj -c Release
```

**Звонки в репозиторий не входят.** Встроенные звонки — записи с [Pixabay](https://pixabay.com/sound-effects/);
их лицензия разрешает использовать звуки внутри программы, но не раздавать файлы отдельно.
Поэтому mp3 лежат только локально (`src/Time2Gadget/Assets/Ringtones/`, см. `.gitignore`) и попадают
внутрь exe и установщика. Сборка из чистой копии репозитория работает, но без встроенных звонков
(можно выбрать свой файл в настройках).

Установщик собирается [Velopack](https://velopack.io):

```
dotnet publish src/Time2Gadget/Time2Gadget.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=false -o publish
vpk pack --packId Time2Gadget --packVersion <версия> --packDir publish --mainExe Time2Gadget.exe --framework net8.0-x64-desktop -o Releases
```

## Как выпустить новую версию

1. Поднять `<Version>` в `src/Time2Gadget/Time2Gadget.csproj`, закоммитить и отправить.
2. В папке `Releases/` должен лежать `full.nupkg` предыдущей версии — тогда Velopack соберёт дельта-обновление
   (иначе сначала `vpk download github --repoUrl https://github.com/alexan-moscow/time2gadget -o Releases`).
3. Собрать (команды выше, `--packVersion` = новая версия, звонки должны лежать в `Assets/Ringtones/`).
4. Опубликовать: `vpk upload github --outputDir Releases --repoUrl https://github.com/alexan-moscow/time2gadget --token <токен gh> --publish --releaseName "Тайм2гаджет X.Y.Z" --tag vX.Y.Z --targetCommitish main`,
   затем добавить описание выпуска (`gh release edit vX.Y.Z --notes-file …`). Описание пишется в [CHANGELOG.md](CHANGELOG.md)
   по единому формату: только разделы, без вводной строки — «Добавлено», «Исправлено», «Изменено» (пустые не пишутся),
   в конце «Проверка» — SHA-256 установщика, отчёт VirusTotal и что известно о срабатываниях. В выпуск на GitHub
   идёт текст раздела этой версии без заголовка «## X.Y.Z», с перенесёнными строками, склеенными в одну
   (в описании выпуска GitHub показывает каждый перенос строки как разрыв).
5. Загрузить `Time2Gadget-win-Setup.exe` нового выпуска на VirusTotal — кнопка в программе найдёт отчёт сама
   по отпечатку файла из выпуска.

Установленные копии найдут выпуск сами (при запуске и раз в сутки) или по кнопке «Проверить обновления».
