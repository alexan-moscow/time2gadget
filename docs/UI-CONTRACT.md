# UI-CONTRACT.md

Точный контракт поведения UI-компонентов. Перед изменением визуального поведения — сверяться с этим файлом (тот же принцип, что в КЛЮЧ24: "перед созданием нового UI-компонента — сначала свериться с UI-CONTRACT.md").

---

## SectorRingControl (кольцо из 8 секторов)

- **Назначение**: выбор пресета времени (5/10/15/20/30/45/60/90 мин) и (после старта) визуализация прогресса.
- **Геометрия**: 8 сегментов-«бубликов» (donut segments) по 45° каждый, с зазором `2°` между соседними (тонкий разделитель) — см. `DESIGN-SYSTEM.md` → Геометрия.
- **Состояния сектора**:
  - `Normal` — `Color.SurfaceSector`, граница `Color.BorderSubtle`, текст `Color.TextSecondary`.
  - `Hover` — фон плавно (`Anim.Hover`) переходит в `Color.SurfaceSectorHover`.
  - `Selected` — фон/граница `Color.Accent`, текст `Color.TextPrimary`. Ровно один сектор может быть `Selected` одновременно.
  - `Disabled`-состояния нет — все 8 секторов всегда кликабельны, независимо от статуса таймера (см. ниже "Логика клика").
- **Логика клика** (реализация — `SelectPresetCommand` в `MainViewModel`, НЕ в code-behind контрола):
  - Если `TimerStatus != Running` → клик выбирает пресет (`SelectedPreset` меняется, время устанавливается).
  - Если `TimerStatus == Running` → клик по сектору НЕ меняет текущий отсчёт.
  - Повторный клик по уже `Selected` сектору, когда таймер `Ready` (не запущен) → эквивалентен нажатию Start (см. §8 BRIEF.md). Эта логика инкапсулирована в одном месте (`MainViewModel.SelectPresetCommand`) — переключаемое поведение, не должна дублироваться в разметке.
- **Не является частью SectorRingControl**: круговой progress-индикатор — отдельный визуальный элемент (см. ниже), физически внутри кольца секторов, но собственный DependencyProperty/собственная отрисовка.

## ProgressRingControl (тонкое внутреннее кольцо прогресса)

- **Назначение**: единственный источник визуализации хода отсчёта. НЕ перекрашивает сектора сам по себе (сектор остаётся `Selected`-цвета всё время, пока выбран).
- **Вход**: `ProgressFraction` (double, 0.0…1.0) — 0 = только что запущен/полное время, 1 = время истекло. Обновляется на каждый UI-tick (см. ARCHITECTURE.md Timer Engine) — НЕ дискретными скачками раз в секунду, а плавно.
- **Цвет**: `Color.Accent` в состояниях `Running`/`Paused`; переключается на `Color.Finish` в состоянии `Finished` (см. ниже).
- **Paused**: дуга прогресса замирает на текущем значении (не двигается, не сбрасывается).

## CenterDisplay

| TimerStatus | Верхняя строка | Нижняя строка (статус) |
|---|---|---|
| `Ready` | выбранное время, `MM:SS` (напр. `30:00`) | `ГОТОВ` |
| `Running` | оставшееся время, `MM:SS`, обновление каждую секунду визуально (внутренний расчёт — непрерывный) | `ОСТАЛОСЬ` |
| `Paused` | оставшееся время на момент паузы (заморожено) | `ПАУЗА` |
| `Finished` | `00:00` | `ГОТОВО` (или аналог, финализируется при визуальном ревью) |

`Finished`: дополнительно — плавная пульсация центра (`Anim.FinishPulse`) и временная смена акцента на `Color.Finish` (сектор/progress-ring), пока пользователь не нажмёт Start (новый цикл) или Reset.

**Часы и дата** (2026-09-27): под статусом «ГОТОВО/ОСТАЛОСЬ» — тонкий разделитель (`Style.ClockSeparator`, виден, если включены часы или дата), под ним часы **сегментным шрифтом как у таймера** с подложкой погасших сегментов (`Style.ClockText`/`ClockGhost`, 13px, приглушённый цвет), под ними дата шрифтом статуса (`Style.DateText`, формат «ВС, 27 СЕНТ»). В компакте — разделитель, затем часы и дата **в одну строку по центру** (11px, зазор 12px), дата там — тем же сегментным шрифтом, что часы, цифрами «ДД.ММ» с подложкой «88.88» (DSEG7 не рисует буквы); отступы разделителя в полном режиме подобраны замером: видимый зазор 8px сверху / 7px снизу; DSEG моноширинный, поэтому секунды не сдвигают строку. Настройки: «Показывать текущее время» (да), «С секундами» (нет), «Показывать дату» (да). Компакт стал выше на 16px (220×156) под эту строку.

**Эффекты в компактном режиме** (2026-09-27): эффекты отсчёта и завершения идут одновременно на кольце полного режима (`EffectOverlay`/`RingGroupScale`) и на прямоугольнике компакта (`CompactEffectOverlay`/`CompactScale`); пульсация в компакте втрое слабее, чтобы не вылезать за окно.

**Угловые кнопки справа**: переключатель автозакрытия вплотную к крестику (правый отступ 32 при ширине кнопки 28 — зазор иконок ~6px); раньше отступ 42 давал наползание на цифры в компакте.

## Control Buttons (нижний ряд)

**Центровка (2026-09-27):** тройка Mute / Start-Pause / Reset симметрична, Start-Pause точно под центром циферблата (в компакте — под центром прямоугольника). Слайдер громкости вынесен из тройки: стоит слева от Mute отрицательным отступом (полный режим −20, зазор 6px; компакт −24), поэтому не сдвигает центровку. Размеры кнопок и зазоры прежние.

| Кнопка | Позиция | Иконка/состояния | Действие |
|---|---|---|---|
| Mute | левая | векторные `Geometry.VolumeUp` / `Geometry.VolumeOff` (при `IsMuted=true`) | `ToggleMuteCommand`, персистентно (см. Settings) |
| Start/Pause | центральная, визуально крупнее/акцентнее двух других | `Geometry.Play` (не `Running`) / `Geometry.Pause` (`Running`) | `StartPauseCommand`. Из `Ready` с 00:00 (после сброса/при запуске) — запускает подсвеченный на кольце пресет (2026-09-27) |
| Reset | правая | `Geometry.Refresh` | `ResetCommand` — возврат к `Ready` с 00:00 (2026-09-27; раньше — к последнему пресету) |

## Мышь / клавиатура (глобально для окна, MVP = локально)

| Ввод | Условие | Действие |
|---|---|---|
| Колесо вверх/вниз над центральной областью | всегда | `AdjustTimeCommand(+1)` / `(-1)` минута; clamp `[1 мин, 24 ч]` |
| `Space` | окно в фокусе | `StartPauseCommand` |
| `R` | окно в фокусе | `ResetCommand` |
| `Esc` | окно в фокусе | остановить и сбросить текущий отсчёт (эквивалент Reset применительно к `Running`/`Paused`) |
| ЛКМ + drag по свободному фону (не по сектору/кнопке) | всегда | перемещение окна (`DragMove()`) |

## Tray

Контекстное меню (ПКМ) — только «Настройки…» и «Выход» (упрощено 2026-09-27: Start/Pause, Reset, Always on Top и автозапуск дублировали окно и окно настроек). **Левый клик по иконке** — показать/развернуть окно (замена пункта «Показать таймер»). Закрытие окна (крестик/системное) → по настройке «При закрытии окна»: сворачивание в трей (по умолчанию) или выход.

**Живая иконка трея** (2026-09-27): повторяет кольцо таймера — тёмный круг, дорожка, дуга прогресса от 12 часов по часовой (`Accent` при отсчёте, `TextSecondary` на паузе), красное кольцо (`Finish`) по окончании. **Эффект завершения дублируется в трей** (2026-09-27) с теми же периодами, что на циферблате: строб — резкие вспышки заливкой середины, пульсация — «дыхание» заливки + утолщение кольца, «Радужная волна» — яркий круг всех цветов (красный → оранжевый → жёлтый → зелёный → голубой → синий → фиолетовый → малиновый, 0.3 с на переход, палитра — `Models/RainbowPalette.cs`, общая для окна и трея); заливка середины играет роль `EffectOverlay`. Эффект в трее и в окне идёт одинаковое время — настройка «Длительность эффекта» (2 с … 5 мин или бесконечно, по умолчанию бесконечно). Если эффекта нет (выключен или истекла длительность), а окно скрыто (в трее или свёрнуто) — кольцо **мигает красным** (0.5 с с заливкой / 0.5 с тусклое), пока окно не покажут или таймер не сбросят. Иконка отрисовывается до того, как станет видимой, — без промаргивания иконкой приложения при запуске. Без отсчёта (Ready) — пустое незаполненное кольцо, НЕ иконка приложения: та сама по себе кольцо, заполненное на ~70%, и в трее выглядела как идущий таймер. Толщина кольца ~11% размера — как у кольца в иконке приложения. Подсказка при наведении — оставшееся время («осталось 04:32» / «пауза, …» / «время вышло!»). Рисуется GDI+ в `TrayService.Update` размером `SmallIconSize`, перерисовка только при видимом изменении (64 шага дуги).

**Переключатель автозакрытия** — угловая кнопка слева от крестика (иконка питания `Geometry.Power`, размер/стиль как у крестика; выкл — `TextSecondary`, вкл — `Accent`). По умолчанию выключен, состояние сохраняется. Когда включён: после отработавшего таймера — **когда звонок отыграет все повторы** (при выключенном звуке — через 3 с после окончания) — выполняется то же, что крестик: свернуть в трей или выйти по настройке «При закрытии окна». Не срабатывает, если пользователь успел сбросить/перезапустить таймер, пока звенело.

**Одна копия приложения** (2026-09-27): повторный запуск не открывает второе окно — он показывает окно уже запущенной копии (даже свёрнутой в трей) и сразу завершается. Реализация — именованный мьютекс `Local\Time2Gadget.SingleInstance` + событие `Local\Time2Gadget.ShowWindow` (`App.xaml.cs`), в пределах пользовательской сессии.

## Compact Mode

**Виджет часов (2026-09-27).** Если таймер не запущен (Ready, 00:00) и включены часы — вместо нулей крупно идёт текущее время тем же сегментным шрифтом (с подложкой), под ним дата «ДД . ММ . ГГ» (короткий год, части разнесены — `CompactDateTemplate`; если дата выключена — место не резервируется). Разделителя в покое нет: его роль играет полоска хода таймера сразу под датой (зазор 4px). Идёт/пауза/закончился — крупно таймер, под разделителем строка «часы + дата» размером как дата в покое (13). Блок прижат к полоске (`VerticalAlignment=Bottom`); высота компакта 132 подобрана замером — самый высокий вариант (таймер ММ:СС + строка часов) помещается без лишнего зазора. Крупный блок растянут на ширину между угловыми кнопками (146px, `Stretch=Uniform`, пропорции шрифта сохраняются). Угловые кнопки в компакте ближе к углам (отступ 5), автозакрытие — под крестиком (шаг 22px). Нижние кнопки — прямоугольные (`Style.RectButton` 36×26, `Style.PrimaryRectButton` 52×28), Play по центру, громкость снаружи слева.

**Размер (2026-09-27):** ползунки «Размер полного вида» и «Размер компактного вида» 80–160% (`AppSettings.FullViewScale`/`CompactViewScale`), `LayoutTransform` на Chrome, окно = содержимое × масштаб + 16.

Прежнее описание (MVP):

Показывает: время (меньший типографический размер, `Type.TimeDisplayCompact`), `ProgressRingControl` (уменьшенный радиус), Start/Pause, Mute, Reset. `SectorRingControl` — `Visibility.Collapsed`. Переключение — пункт контекстного меню, анимированный переход `Anim.ModeSwitch`. Оба режима используют одну и ту же `MainViewModel` — никакого дублирования состояния между режимами.

## Подсказки (добавлено 2026-09-27)

Собственные всплывающие подсказки вместо стандартного `ToolTip` (`Controls/HintService.cs`). Стандартные `ToolTip` в главном окне не используются.

- **Появление:** только после того, как мышь **неподвижно** провисела над элементом 2 сек (дрожание ≤3px не считается движением); короткий fade-in (~140мс).
- **Исчезновение:** сразу при любом заметном движении мыши, клике, колесе, уходе мыши с окна или потере фокуса окном; fade-out ~90мс. После исчезновения — снова 2 сек неподвижности до следующей.
- **Вид:** `Style.HintBubble`/`Style.HintText` в `Theme.xaml` — фон окна, рамка 1px с градиентом акцент → нейтральная, скругление 8, мягкая тень, шрифт 11.5, ширина до 260. Располагается под курсором.
- **Текст зависит от состояния** и описывает, что сделает действие именно сейчас. Элемент помечается `HintService.Key`, текст выдаёт `MainViewModel.GetHint(key, tag)` в момент показа:

| Элемент (ключ) | Текст |
|---|---|
| Сектор (`Preset`) | Ready/Finished: «Запустить таймер на N минут»; тот же сектор во время отсчёта/паузы: «Добавить N минут к текущему таймеру»; другой сектор: «Сбросить и запустить заново на N минут» |
| Start/Pause (`StartPause`) | «Пауза» / «Продолжить отсчёт» / «Запустить этот таймер ещё раз» / «Запустить отсчёт» / при 00:00 — «Сначала выберите время на кольце» (+ хоткей) |
| Reset (`Reset`) | «Сбросить таймер на 00:00 (R)»; при звонке — «Выключить звонок и сбросить…» |
| Центр (`Center`, `CompactCenter`) | клик — компактный режим / вернуться к полному виду; колесо ±1 мин (только когда не идёт отсчёт) или «потяните — переместить окно» |
| Mute / громкость / шестерёнка / крестик | «Выключить/Включить звук звонка», «Громкость звонка: N%», «Настройки», «Свернуть в трей»/«Закрыть приложение» (по настройке закрытия) |

## Обновления (2026-09-27)

- **Автопроверка раз в неделю**: через 1 мин после запуска и далее каждые 6 ч проверяется, прошло ли ≥7 дней с последней *успешной* проверки (`AppSettings.LastUpdateCheckUtc`, переживает перезапуски). Проверка тихая: ошибки сети не показываются.
- **Нашлось обновление** → вверху окна настроек жёлтый баннер «Найдено обновление X. Обновить?» с кнопкой; шестерёнка в главном окне **жёлтая и мигает** (`Brush.UpdateAccent`, 0.7 с), подсказка шестерёнки — «Настройки — доступно обновление X».
- **Внизу настроек** — раздел «Обновления»: текущая версия, кнопка «Проверить обновления» (ручная проверка всегда, со статусом: «Проверяем…» / «Установлена последняя версия» / «Доступна версия X» / «Не удалось проверить — нет связи с GitHub»).
- **Установленная копия** (Velopack): кнопка «Обновить» скачивает выпуск из GitHub Releases с прогрессом, ставит и перезапускает программу; если идёт отсчёт — сначала спрашивает подтверждение (таймер сбросится). Портативный zip из выпуска (Velopack Portable, запуск через `Тайм2гаджет.exe`, внутри есть `Update.exe`) тоже обновляется на месте. Не обновляется только одиночный single-file exe из `bin\Release\publish` (в выпуски не выкладывается): у него кнопка «Скачать» открывает страницу выпуска.

## Frozen / Baseline статус

До первого визуального ревью пользователем — ничего не считается FROZEN, всё в статусе IN PROGRESS. После явного визуального одобрения главного экрана (Normal mode) — статус переводится в BASELINE (см. `BRIEF.md` §23), дальнейшие правки — по конкретному дефекту/запросу, не переоткрывать бездумно.
