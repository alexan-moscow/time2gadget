# PRODUCT.md

Конденсированный продуктовый обзор (аналог PRODUCT.md в КЛЮЧ24). Полный исходный бриф — `BRIEF.md`.

## Продукт
Компактный desktop-таймер-гаджет для Windows 10 (WPF, .NET 8). Один пользователь, один процесс, без сети/сервера/аккаунтов.

## Пользователь
Единственная роль: **Пользователь** — открывает приложение, выбирает время из 8 пресетов (5/10/15/20/30/45/60/90 мин), запускает/ставит на паузу/сбрасывает отсчёт, держит окно поверх остальных или в трее.

## Ключевой сценарий
1. Приложение запущено (или разворачивается из трея).
2. Пользователь кликает сектор → время выбрано.
3. Повторный клик по тому же сектору (или кнопка Start) → отсчёт идёт.
4. По завершении — сигнал + визуальная индикация, кнопка Start снова доступна.

## Функциональный список (MVP)
- Кольцо из 8 кликабельных секторов-пресетов.
- Круговой прогресс-индикатор.
- Центральный дисплей времени + статус.
- Start/Pause/Reset/Mute.
- Колесо мыши (±1 мин над центром).
- Горячие клавиши (Space/R/Esc).
- Always on Top.
- Системный трей + меню.
- Автозапуск с Windows.
- Сохранение настроек (JSON).
- Compact-режим.
- Portable-сборка.

## Явно вне MVP (будущие возможности, не реализуются сейчас)
- Глобальные (system-wide) горячие клавиши.
- Кастомные пользовательские пресеты времени сверх заданных 8.
- Windows Toast Notification (опционально, не обязательно).
- Множественные одновременные таймеры.
- Облачная синхронизация/аккаунты — принципиально не в объёме продукта.
