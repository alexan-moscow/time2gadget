## Доработки после MVP (2026-09-27, по ревью пользователя)
- **Логика секторов:** первый клик — сразу старт; повторный клик по активному — добавить его время; клик по другому — перезапуск с новым временем. Сброс и старт приложения — 00:00.
- **Внешний вид:** единые отступы 16px, «МИН» убрана из секторов (число в Viewbox по площади сектора), векторные шестерёнка/крестик с отцентрованной подсветкой, вертикальный слайдер громкости рядом с Mute (в обоих режимах), Compact — скруглённый прямоугольник без статусных подписей.
- **Звонок:** «сколько раз звонить» (1–10) вместо интервала/длительности; каждый повтор — полное проигрывание звука (раньше повторы могли накладываться). Выбор мелодии (4 сгенерированных + свой файл), громкость, устройство вывода, дефолты: 50%, «Мягкий перезвон».
- **Эффекты циферблата:** во время отсчёта (Пульсация/Вспышка/Дыхание) и при завершении (Пульсация/Строб/Цветовая волна) — по умолчанию выключены. **Вспышка при завершении проверена вживую** (реальная минута ожидания).
- **Окно настроек:** полностью тёмные выпадающие списки (retemplate ComboBox).
- **Переименование:** TimerGadget → Time2Gadget (Тайм2гаджет), см. DECISIONS.md.
- **Подсказки (ПРОВЕРЕНО скриншотами):** собственные всплывающие подсказки на всех элементах, появление через 2 сек неподвижности, мгновенное исчезновение при движении, текст по состоянию таймера — см. UI-CONTRACT.md → Подсказки.

## Реальные находки этого прохода (см. DECISIONS.md для деталей)
- **Наложение кнопок управления на нижние сектора кольца** — обнаружено на первом реальном скриншоте, исправлено уменьшением радиусов кольца + вертикальным сдвигом композиции. Подтверждено повторным скриншотом — наложение устранено.
- **SendKeys-эмуляция буквы "R" не работает при русской раскладке клавиатуры ОС** — это ограничение тестовой методологии (SendKeys резолвит символ через текущую раскладку), НЕ баг приложения: реальное физическое нажатие клавиши (проверено через прямой virtual-key код `0x52`, независимый от раскладки) сработало корректно.
- **UseWPF + UseWindowsForms** в одном проекте даёт project-wide неоднозначность типов (`Point`/`UserControl`/`Application`) через implicit usings — решено явным `<Using Remove>` в `.csproj`.

## Технический долг / что осталось проверить
1. Mute-переключение и колесо мыши — реализованы, но не проверены интерактивно.
2. Compact Mode — геометрия подобрана расчётно (по аналогии с Normal), не осмотрена вживую; возможна потребность в точечной подгонке после визуального ревью пользователем.
3. Системный трей (иконка/меню/сворачивание) — не осмотрено вживую.
4. Автозапуск с Windows — код есть (`AutostartService`, реестр `Run`), не проверялся фактическим перезапуском Windows.
5. ~~Состояние `Finished` не воспроизведено вживую~~ — вспышка завершения проверена 2026-09-27; остальные эффекты завершения (Пульсация/Цветовая волна) вживую не осматривались.
6. Иконка трея использует системную заглушку `SystemIcons.Application` — нет собственного `app.ico` (осознанная точка расширения, см. `DECISIONS.md`).
7. Звук завершения — 4 мелодии, синтезированные в коде (`RingtoneGenerator`), + свой файл. Заменить на реальные записи из интернета — см. «Следующие шаги».
8. Portable-публикация — framework-dependent (требует .NET 8 Desktop Runtime на целевой машине), не self-contained.

## Известные ограничения окружения
- На машине разработки изначально отсутствовал `.NET SDK` — установлен в рамках PHASE 0 через `winget`.
- Финальная тонкая визуальная подгонка (Compact Mode, состояние Finished, трей) требует осмотра пользователем на реальной машине — см. п.2/3/5 технического долга выше (`BRIEF.md` §23 UI FREEZE).
